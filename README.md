## 二、选题总览（Selected Tasks）

本次考核我选择的主线是 **「电源类电子产品的实测 → 逆向 → 改造」**。

三个阶段不是三个孤立作业，而是同一条技术链路的递进应用：
用仪器把真实数据测出来 → 把电路看懂、把成本算清 → 用低成本方案改好并通电验证。

### 为什么这样选（面试会问）

**跨专业视角：** 我的专业是新能源汽车检测与维修，专业课围绕动力电池与电气系统展开。
我自研的 IP5306 充电宝板，本质上就是一套微型 BMS。
选择拆解一台商用旧充电宝，是把专业课里学到的**电池容量、内阻、充放电效率、
保护策略**这些概念，放到一个 20 元级的真实产品上做一次完整的验证与改造。

**三阶段如何互相咬合：**

- 课题 07 用仪器**测出**「标称容量与真实可用能量之间的差距」——这是问题的发现
- 项目五**拆开**这台电器，还原电路与 BOM，**解释**这个差距从哪来——这是归因
- 项目五第 ④ 项在此基础上**设计并动手验证**一套智能化改造方案——这是解决

一份数据贯穿三个阶段，而不是三份互不相干的报告。

## 四、过程留痕原则（Process Integrity）

本仓库遵守考核大纲的诚信要求：

1. **所有 `raw_data/` 与 `process_logs/` 中的数据均为本人现场实测**，未做任何数值修改；
   原始文件一经生成即提交，后续分析只新增文件，不改写原始记录。
2. 使用 AI 工具辅助写代码、查资料、排障是**被鼓励**的，相关对话摘要记录在
   [`03-AI-Collaboration/`](03-AI-Collaboration/)，并且**包含 AI 给出错误答案的记录与我的验证过程**。
3. 提交历史（`git log`）按天推进，每一次提交对应一次真实的动手进展。
4. 图表与结论由 `analysis/` 中的脚本从原始数据自动生成，**可复现**。
