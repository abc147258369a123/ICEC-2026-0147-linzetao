## 2. 关键电路说明

### 2.1 IP5306 主功率级

- `VIN`：5 V 充电输入
- `SW` → `L1` → `BAT+`：同步升压/降压功率级，负责充电与 5 V 输出
- `VOUT`：升压输出，经 `C6/C7 = 22 µF` 滤波
- `KEY`（第 5 脚）：经 `R5 = 10 kΩ` 上拉，接按键 `SW1` 到地，实现开关机与电量显示触发
- `LED1 / LED2 / LED3`：电量指示，接 4 颗 LED（含 1 颗双色）

### 2.2 电池保护级（IP3005B）

- `C8 = 100 nF` 为保护 IC 供电去耦
- `R1 = 100 Ω` 串在 `BAT+` 采样路径上
- `C9 = 22 nF` 为 `VM` 端电流检测滤波
- `EP`（散热焊盘）接 `GND`

### 2.3 电源切换通路（待复核项）

`Q1 (AO3401A)` 位于 `BAT+` 与 `VOUT` 之间，栅极由两路控制：

- `R4 = 100 kΩ`：栅极到 `GND`（默认下拉）
- `D1 = SS34`：从 `+5V` 引入到栅极节点

**设计意图推断：** 当 `+5V` 输入存在时，通过 `D1` 把栅极拉高，关断 P-MOSFET，
断开电池对 `VOUT` 的直连；无输入时 `R4` 把栅极拉低，`Q1` 导通，电池经 `Q1` 向 `VOUT` 供电。

**待复核：** `D1` 的方向与 `VOUT` 的接入位置需结合实物复测确认——
此处是本板最值得用万用表逐点验证的一段，也是与商用方案对比时的重点。

## 3. 附带工具：`crop.js`

为了逐块放大检查原理图细节，我写了这个纯 JavaScript 的 PNG 裁剪/放大工具：

- 手写 PNG 解析：读取 `IHDR`/`IDAT`/`PLTE`/`tRNS` 块，`zlib.inflateSync` 解压
- 逐行反滤波：完整实现 `None / Sub / Up / Average / Paeth` 五种 PNG 滤波器
- 支持 `colorType` 0/2/3/4/6 与调色板、透明度
- 手写 CRC32 查表算法与 PNG 分块封装，`zlib.deflateSync` 重编码输出 RGBA

**零第三方依赖**，只用了 Node 内置的 `fs` 与 `zlib`。

用法：

```bash
node crop.js <输入.png> <输出.png> <cropX> <cropY> <cropW> <cropH> <放大倍数>
```

## 5. 与项目五的关系

拆解商用旧电器时，本板作为**对照基线**：

- 商用方案为了压成本，通常会砍掉独立保护 IC（改为软件保护）或用更便宜的升压芯片；
  对照本板可以量化「多一颗 IP3005B 换来什么」。
- 本板是**分立方案**，商用板多为**高集成方案**，
  两者对比能直接产出项目五第 ② 项需要的《供电/控制框图》分析深度。
- 本板的 BOM 我手上有真实打样报价，可作为项目五第 ③ 项 BOM 表的**成本参照锚点**。
