## 这个目录收什么

你把照片**按下面的 6 个子目录分类丢进去**就行，不用改名（但建议看一眼命名规范）。

| 子目录 | 放什么 | 必交 |
| --- | --- | --- |
| `01-整机外观六面/` | 拆解前的整机，正面/背面/侧面/顶部/底部/接口特写 | ✅ |
| `02-铭牌特写/` | 铭牌或丝印标签，能看清型号、输入输出参数、生产信息 | ✅ |
| `03-拆解分步/` | **从完整到取出主板的每一步**，一步一张 | ✅ |
| `04-爆炸拆解图谱/` | **所有零件按装配顺序拉开排布的合影，标件号** | ✅ **这一项 15 分的核心** |
| `05-结构件与尺寸/` | 外壳、卡扣、螺柱、导线的特写 + 卡尺实测尺寸 | 建议 |
| `06-主板正反面/` | 主板正面、背面，丝印清晰、光线均匀 | ✅ |

## 文件命名规范（建议，不强求）

```
01_整机正面.jpg
02_整机接口.jpg
03_铭牌.jpg
04_卸下螺丝.jpg
05_开壳.jpg
06_内部总览.jpg
07_主板正面.jpg
08_主板背面.jpg
09_爆炸图谱_全件.jpg
10_结构件尺寸_外壳.jpg
```

**三条原则：**

1. **序号在最前面** —— 文件管理器按名排序就是拆解顺序，评委一眼能看出你是一步步拆的
2. **名字能看出内容** —— 别用 `IMG_20261021_1532.jpg`
3. **不要用中文以外的特殊符号**（`#`、`%`、`&` 在网页 URL 里会出问题）

## 过程分步照片：评委要看的是「顺序」

这是 15 分里最容易丢分的地方。光有零件照不够，**必须能看出拆解的顺序**。

标准的 8 步（你可以更多，但不能更少）：

| 步骤 | 拍什么 | 关键点 |
| --- | --- | --- |
| 1 | 拆解前的整机 | 六面都拍，证明是完整状态 |
| 2 | 铭牌特写 | 后面 BOM 和参数都靠它 |
| 3 | 螺丝位置特写 | **拍下螺丝数量与规格**（M2 还是 M3、多长） |
| 4 | 卸下螺丝 | 螺丝摆在一起拍，证明没丢 |
| 5 | 开壳瞬间 | 卡扣位置、有无胶水/超声波焊 |
| 6 | 内部总览 | 电池、主板、结构件的相对位置 |
| 7 | 分离出的各部件 | 按顺序摆开 |
| 8 | **爆炸图谱** | 见下一节 |

## ④ 爆炸拆解图谱：这一张决定 15 分里的分量

**要求：**

- [ ] 所有零件**按装配顺序**从左到右（或从上到下）排开
- [ ] 每个零件旁边**标件号**（1、2、3……）
- [ ] 件号要和 BOM 表、结构件清单一对应
- [ ] 背景干净（白纸或深色布），光线均匀
- [ ] 从**正上方垂直拍摄**，避免透视变形

**推荐的标注方式：**

- 拍完后用手机自带编辑器或电脑画图，在每个零件旁边加数字
- 或者在零件下方垫小纸条写数字再拍
- **一定要有件号**，光摆整齐不给分

**零件清单（按你的实物填）：**

| 件号 | 名称 | 材料 | 数量 |

| 4 | 18650 电池座 / 弹片 | | |

## 安全提醒

- 拆解前**已断电并拔掉插头**
- 若充电器带市电输入（220V 一次侧），**一次侧大电容必须放电后再碰**
- 焊接、通电测试前先用万用表确认无短路
