# 供电框图（把导出的图放这个文件夹）

**期望文件：** `供电框图.png`（或 .pdf）

## 必须体现

从 USB 输入到各电源轨的完整链路，**每个节点标实测电压**（万用表量的，不是 datasheet 标称）。

参考骨架（按你的实物调整）：

```
USB 5V 输入
   ├─→ TVS / 保险丝
   ├─→ 充电管理 IC ─┬─→ BAT+ → 18650（实测满电 4.20 V）
   │                └─→ LED 指示
   └─→ （若有）LDO / DC-DC → 3.3 V 或 5 V
```
