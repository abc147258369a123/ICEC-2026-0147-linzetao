# 控制框图（把导出的图放这个文件夹）

**期望文件：** `控制框图.png`（或 .pdf）

## 必须体现「控制 IC 收到了什么、控制了什么」

| 控制关系 | 要写清 |
| --- | --- |
| 输入检测 | 怎么判断插了 USB、输入电压门槛 |
| 充电电流设定 | 靠哪个引脚、外部电阻**实测阻值**多少 |
| 充电状态输出 | LED / 状态引脚，各状态什么电平 |
| 充满判定 | 具体条件：电流降到多少？电压到 4.2 V？有无 ΔV 检测？ |
| 保护动作 | 过温 / 反接 / 短路时切断什么 |

## 面试会问

> 「你这台充电器怎么判断充满的？」

要能从框图指出**具体引脚和判定条件**，不能只说「应该有个芯片管着」。
