# ② 主板芯片丝印溯源与供电 / 控制框图（15 分）

> 考核大纲原文：
> **主板芯片丝印溯源与供电/控制框图**（15 分）

**改造对象：** 单节 18650 锂电池充电器

---

## 我实际用的逆向方法

> 以下是拆解时记下的方法，按顺序执行：

1. **拆开外壳看 PCB，先找主控**
2. **看丝印**，根据丝印找芯片的数据手册
3. 根据**数据手册的引脚定义** + **PCB 上的走线**，推出每一根线
4. **先推电源线**（VCC 和 GND），**后推信号线**
5. **电阻大小看丝印**（贴片电阻三位/四位码）
6. **电容大小靠经验**

### 两条可以补强的地方（面试会问）

| 器件 | 读不出来时怎么办 |
| --- | --- |
| 电容 | 只看外观确实只能靠经验估。**拆下来用电容表量一次**就能确认，量完再焊回去——这一步能把「估计」变成「实测」 |
| 电阻丝印模糊 | 万用表直接量阻值；`000` 是 0 Ω 跳线，别当成电阻 |

## 对照 15 分，还缺这三块

| 大纲要求 | 现状 | 怎么补 |
| --- | --- | --- |
| **芯片丝印溯源** | ❌ **没有清单** | 每颗芯片一行：位号、丝印字符、推断型号、厂商、功能、封装、datasheet 链接、**实测引脚电压** |
| **供电框图** | ❌ 无 | 从 USB 输入 → 充电管理 IC → 电池座 的链路，每个节点标**实测电压** |
| **控制框图** | ❌ 无 | 控制 IC 收到了什么、控制了什么（尤其：**怎么判断充满**） |

### 最快补齐顺序

1. **丝印清单**（半小时）：对着主板照片，把每颗芯片的丝印抄下来，逐个查数据手册核对引脚
2. **供电框图**（1 小时）：你已经有逆向原理图了，**直接从原理图归纳出电源链路**即可，不用重新追线
3. **控制框图**（半小时）：同样从原理图归纳，重点标清楚充满判据

> 你现在**已经完成逆向原理图了**，这三块其实是从同一份原理图里「抽」出来的三张图，
> 工作量比重新追线小得多。

## 丝印溯源表要哪些列

| 列 | 填什么 | 举例 |
| --- | --- | --- |
| 位号 | PCB 上的位号 | `U1` |
| 丝印字符 | 芯片表面印的字，**原样抄** | `LTH7` |
| 推断型号 | 查证后的完整型号 | `TP4056` |
| 厂商 | 品牌 | 南京拓微 |
| 功能 | 一句话 | 单节锂电线性充电管理 |
| 封装 / 引脚数 | | SOP-8 / 8 |
| datasheet | 链接或文件名 | `TP4056.pdf` |
| **实测引脚电压** | **万用表实测** | `VIN=5.02V` |
| 备注 | 判断依据、疑点 | 丝印与 TP4056 引脚定义一致 |

> **「实测引脚电压」这一列是拿分点。**
> 抄 datasheet 的标称值不加分，万用表量出来的才证明你真碰过板子。
