## 核心交付物：`02-芯片丝印清单/丝印溯源表.csv`

**已经建好模板，直接用 Excel 打开填。**

| 列 | 填什么 | 举例 |
| --- | --- | --- |
| 位号 | PCB 上的丝印位号 | `U1` / `Q2` / `D3` |
| 丝印字符 | **芯片表面印的字**（原样抄） | `B6286` |
| 推断型号 | 检索后确认的完整型号 | `TP4056` |
| 厂商 | 品牌 | 南京拓微 |
| 功能 | 一句话说明 | 单节锂电线性充电管理 |
| 封装 | 封装形式 | SOP-8 |
| 引脚数 | 引脚数量 | 8 |
| datasheet | 文档链接或文件名 | `TP4056.pdf` |
| 实测引脚电压 | **万用表实测**（不是查资料） | `VIN=5.02V` |
| 备注 | 判断依据、疑点 | 丝印与 TP4056 引脚定义一致 |

> **「实测引脚电压」这一列是拿分点。** 抄 datasheet 的标称值不加分，
> 万用表量出来的才证明你真的碰过板子。

### 丝印溯源的实操方法

1. **先拍清楚**：手机微距模式 + 侧光（45° 打光，丝印是凹/凸的，侧光下最容易看清）
2. **抄下丝印字符** —— 注意丝印常是缩写（`B6286` ≠ 型号，可能是 `TP4056` 的代号）
3. **按「丝印 + 封装 + 引脚数」组合检索**：
   - 立创商城「丝印反查」
   - 半导小芯（`www.semiee.com`）
   - 芯查查
4. **拿 datasheet 核对引脚定义** —— 这是最关键一步，能验证你的推断对不对
5. **上电实测引脚电压**，和 datasheet 的典型应用对不上就说明推错了

## `04-供电框图` 怎么画

**必须体现「从输入到各电源轨」的完整链路**，每个节点标实测电压。

18650 充电器的典型链路（按你的实物调整）：

```
USB 5V 输入
   │
   ├─→ TVS / 保险丝（保护）
   │
   ├─→ 充电管理 IC（如 TP4056 类）
   │        │
   │        ├─→ BAT+ → 18650 电池（实测 4.20 V 满电）
   │        └─→ LED 充电指示
   │
   └─→ （若有）LDO / DC-DC → 3.3 V 或 5 V 供控制器
```

**画图要求：**

- [ ] 每个节点标 **实测电压**（万用表量的，不是标称）
- [ ] 标出**充电路径**和**供电路径**用不同颜色
- [ ] 标出**电池保护**在哪一级（DW01 / 自带保护 / 无）
- [ ] 标注你打算**从哪里取电给改造模块**（对应第 ④ 项）

**工具：** 立创 EDA 画、Visio、draw.io、甚至 PowerPoint 都行，导出 PNG。

## `05-控制框图` 怎么画

体现「**控制 IC 收到了什么、控制了什么**」。

| 控制关系 | 说明 |
| --- | --- |
| 输入检测 | 是否插了 USB、输入电压多少 |
| 充电电流设定 | 靠 PROG 脚的外部电阻定，**要标出电阻实测阻值** |
| 充电状态输出 | LED 指示 / 状态引脚 |
| 充满判定 | 判定条件（电流降到多少 / 电压到 4.2 V / 有无 ΔV 检测） |
| 保护动作 | 过温 / 反接 / 短路时切断什么 |

**面试会问：** 「你这台充电器怎么判断充满的？」
你要能从框图指出具体引脚和判定条件，不能只说「应该有个芯片管着」。

## `03-逆向原理图/逆向说明.md` 要写什么

模板已经建好，填这四块：

1. **抄图方法** —— 怎么从板子走线反推的（追线、蜂鸣档测通断、逐段标记）
2. **元件参数怎么确定** —— 贴片电阻电容拆下来量的？还是读码？读不清怎么办
3. **与标准应用电路的差异** —— 厂家做了什么改动、为什么
4. **不确定的地方** —— 哪几根线没追清、哪几个元件没认出来

> 第 4 块**必须老实写**。面试第 ④ 项考「客观承认局限」，
> 承认「这两个元件我没认出来」比硬编一个型号安全得多。
