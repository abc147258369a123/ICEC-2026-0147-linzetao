## 6. 面试预演：这一项目必被追问的问题

> 面试第 1 项 4 分专门考察「项目真实性与过程数据溯源」。先把答案想清楚：

1. 你拆这台电器时，**第一个拆不下来的地方**是哪里？怎么解决的？
2. BOM 表里**哪一颗料的价格最出乎你意料**？为什么？
3. 你的改造方案里，**最大的工程折中是哪一个**？如果预算砍半怎么办？
4. 实测数据和 datasheet 标称值**对不上的地方**是哪一处？你怎么判断是谁错了？
5. 如果要求**断网离线**运行，你的方案要改哪里？
6. 你的改造会不会带来**安全隐患或隐私问题**？怎么规避？
7. 现在回头看，**哪一步你会用完全不同的做法重做**？
