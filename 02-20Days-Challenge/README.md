## 强制要求：跨多日连续过程数据 `process_logs/`

考核大纲对这一阶段反复强调 **「强制要求提交跨多日连续过程数据」**。
这不是可选加分项，是**准入条件**。

### 提交规则

1. 文件名格式：`YYYYMMDD_简述.csv` 或 `YYYYMMDD_简述.jsonl`
2. **每天至少一次提交**，提交信息写清当天做了什么，例如：
   ```
   git commit -m "day03: 完成主板丝印溯源，测出 IP5306 待机电流 62uA"
   ```
3. 日志要包含**真实的时间戳与真实数字**，包括失败记录。
4. 遇到卡壳的那天也要提交，写清卡在哪、怎么排查的——
   **面试第 4 项「心理抗压能力与受挫归因模式」正是看这些记录。**

### 日志格式示例（CSV）

```csv
timestamp,event,detail,value,unit,status
2026-10-24T14:32:11,teardown,拆下后盖卡扣,4,pcs,ok
2026-10-24T15:10:03,measure,主板待机电流,62,uA,ok
2026-10-25T09:05:44,probe,U1 VIN 对地阻值,1.2,Mohm,suspect
2026-10-25T09:41:20,debug,VIN 阻值异常复测（换表笔）,8.6,Mohm,resolved
```
