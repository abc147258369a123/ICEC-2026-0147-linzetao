## 每项课题的硬性交付清单

无论选哪两个课题，评审会逐条对照下表。缺失任一项都会被扣分：

- [ ] **`raw_data/` 原始数据表** —— 现场采集的原始文件，未经修改
- [ ] **本人现场同框照片** —— 人与测量场景同时出现（证明是本人到场）
- [ ] **分析报告 `REPORT.md`** —— 含数据表、图表、结论
- [ ] **分析脚本 `analysis/`** —— 从原始数据生成图表的可复现代码
- [ ] **采样说明** —— 时间、地点、天气/环境、仪器型号、采样边界

## 采样纪律（很重要，面试会追问）

1. **一次采样一个文件**，文件名带时间戳，例如 `20261016_0812_431门口.csv`。
2. **当场记录异常**，例如「第 3 组数据因有人经过导致读数跳变」，
   写在 `REPORT.md` 的「异常记录与处理」一节。**异常数据不要删，要解释。**
   面试第 1 项考察的就是「异常数据原因及排障细节」。
3. **照片要带 EXIF**，手机相册原图直出，不要用截图或转发后的压缩图。
4. 采样完成后**当天提交一次 Git**，让提交时间线与采样时间线对得上。
