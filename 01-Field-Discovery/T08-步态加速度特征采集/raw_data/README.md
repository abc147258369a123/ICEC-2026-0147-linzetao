# raw_data · 课题 08 原始数据与现场照片

> 考核大纲对阶段一的硬性要求：
> **「须包含本校实地采样原始数据表（`raw_data/`）与本人现场同框照片」**
> 缺这两项，课题 08 不算完成。

---

## 一、要放什么

### 1. 四份 phyphox 原始导出文件（必交）

把手机里 phyphox 导出的 **xlsx 原文件**直接复制进来，**不要用 Excel 另存**（另存会改列名和精度）。

按这个规则改名：

| 原始文件名可能是 | 改成 |
| --- | --- |
| `Accelerometer (with g).xlsx` 等 | `20261123_01_静止站立.xlsx` |
| | `20261123_02_平地行走.xlsx` |
| | `20261123_03_快跑.xlsx` |
| | `20261123_04_上下楼梯.xlsx` |

**每个文件应包含 5 列**：时间、a_x、a_y、a_z、合加速度（Absolute acceleration）。

> 如果导出的是 CSV 也可以，但**四个文件都要有**，而且文件名里的序号要和
> `REPORT.md` 表 1 的行顺序一致。

### 2. 本人现场同框照片（必交）

| 照片 | 内容要求 |
| --- | --- |
| `20261123_onsite_走路.jpg` | **人 + 手机 + 采集场景**同框，能看出在走路 |
| `20261123_onsite_跑步.jpg` | 能看出在跑步 |
| `20261123_onsite_楼梯.jpg` | 能看出在楼梯上 |

**要点：**

- 照片里要能看出**手机是怎么拿的**（握在手里 / 揣兜里 / 绑在身上）——
  这直接关系到报告 §7 里「握持甩动导致伪峰值」那条误差分析
- 地点能看出是**校内**（教学楼、操场、楼梯间都行）
- 原图直传，**别用微信/QQ 转发**（会抹掉 EXIF 拍摄时间）

## 三、提交前自检

- [ ] **4 个** xlsx 文件都在，命名带 `01`~`04` 序号
- [ ] 每个文件打开能看到 **时间 / a_x / a_y / a_z / 合加速度** 五列
- [ ] 现场同框照片里能认出是**你本人**
- [ ] 照片能看到**手机拿在哪里**（这是报告误差分析的关键证据）
- [ ] 照片属性里「拍摄日期」不为空

## 四、为什么原始文件这么重要

`REPORT.md` 里所有数字（标准差 0.15 / 2.85 / 12.20 / 3.28、峰值 66.26、主频 1.92 Hz、
78 个窗口 96.2% 正确率）**都必须能从这 4 个文件重新算出来**。

面试第 ① 项会拿你的 `git log` 和数据追问：
**「你这个 66.26 的峰值是哪一段算出来的？」**
—— 你要能打开对应文件、指出是哪几秒、给出算法。

**原始文件在，这些都能答；原始文件不在，所有数字都成了孤证。**
