## 二、采样率与「非严格等间隔」（实测）

四个文件的实际采样参数（从原始时间列直接算出）：

| 文件 | 点数 | 时间跨度 | 平均采样率 | 相邻点间隔 |
| --- | --- | --- | --- | --- |
| 静止站立 | 3838 | 9.473 s | **405.1 Hz** | 恒定 2.47 ms |
| 平地行走 | 5121 | 12.647 s | **404.9 Hz** | 2.47 ~ **9.87** ms |
| 快　跑 | 4000 | 9.880 s | **404.8 Hz** | 2.47 ~ **9.87** ms |
| 上下楼梯 | 7191 | 17.751 s（t 从 2.760 s 起） | **405.1 Hz** | 恒定 2.47 ms |

**平均采样率稳定在 404.8~405.1 Hz**，与报告 §2.3 的「约 405 Hz」一致。

但注意「相邻点间隔」那一列：**平地行走与快跑两个文件出现了 9.87 ms 的间隔，正好是 2.47 ms 的 4 倍**——
说明 phyphox 在这两段里**丢过连续采样点**。

这正是报告 §7 里「时间戳非严格等间隔，FFT 统一按平均采样率处理会带来约 1% 主频偏差」
那条误差的**实测依据**，不是估的。

## 三、统计值怎么复现（关键）

`REPORT.md` 表 2 的所有数字，都能从这 4 个文件按下面的窗口复算出来：

| 状态 | 统计窗口 | 复算结果 vs 报告 |
| --- | --- | --- |
| 静止站立 | 0 ~ 9.5 s（全部） | 均值 9.77 / 标准差 0.15 / 峰值 10.81 ✅ **完全一致** |
| 平地行走 | 0 ~ 12.0 s | 均值 9.88 / 标准差 2.85 / 峰值 20.65 ✅ **完全一致** |
| 快　跑 | **0 ~ 9.0 s** | 均值 18.37 / 标准差 12.19 / 峰值 66.26 ✅ **完全一致** |
| 上下楼梯 | 3.8 ~ 19.8 s | 均值 9.84 / 标准差 3.28 / 峰值 26.23 ✅ **完全一致** |

复现代码：

```python
import pandas as pd, numpy as np

WINDOWS = {
    "静止站立": (0.0, 9.5),
    "平地行走": (0.0, 12.0),
    "快跑":     (0.0, 9.0),   # 剔除末尾约 0.9 s 的收尾段
    "上下楼梯": (3.8, 19.8),  # 剔除起步与收尾
}

for name, (lo, hi) in WINDOWS.items():
    f = {v: k for k, v in [
        ("20261123_01_静止站立_213835.xlsx", "静止站立"),
        ("20261123_02_平地行走_211538.xlsx", "平地行走"),
        ("20261123_03_快跑_213726.xlsx", "快跑"),
        ("20261123_04_上下楼梯_213805.xlsx", "上下楼梯"),
    ]}[name]
    df = pd.read_excel("raw_data/" + f)
    t = df.iloc[:, 0].values.astype(float)
    a = np.sqrt(df.iloc[:, 1]**2 + df.iloc[:, 2]**2 + df.iloc[:, 3]**2).values
    m = (t >= lo) & (t <= hi)
    print(name, "均值 %.2f 标准差 %.2f 峰值 %.2f"
          % (a[m].mean(), a[m].std(), np.abs(a[m]).max()))
```

## 五、关于「数据是否原始」的说明

4 个 xlsx 是 **phyphox 原样导出，未做任何修改**——没有改列名、没有删行、没有重算。

所有特征提取、窗口切分、FFT 主频都发生在**分析环节**，不影响 `raw_data/` 里的原始文件。
任何人拿这 4 个文件按第三节的窗口重算，都能得到与报告表 2 完全一致的数值。
