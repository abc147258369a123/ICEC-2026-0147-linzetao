## AI 的回答要点

1. 三个概念：本地仓库 / 远程仓库 / commit-push 的区别
2. 一次性配置：`user.name`、`user.email`、`init.defaultBranch`、`core.quotepath false`
   （最后一项对中文文件名必需）
3. 在 GitHub 网页建空仓库时**不能勾选** Add README，否则首次推送会冲突
4. 首次推送五连：`git init` → `git add .` → `git commit` → `git branch -M main`
   → `git remote add origin` → `git push -u origin main`
5. 认证走 Git Credential Manager 浏览器登录；若必须用密码则需 Personal Access Token
6. 日常只有 4 条命令：`git status` / `git add .` / `git commit -m "..."` / `git push`
7. 一个约束提醒：**视频和大图不要进仓库**（单文件 100MB 上限）
